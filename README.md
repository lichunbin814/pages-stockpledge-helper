# Stock Pledge Loan Calculator

A tool for evaluating stock pledge loan risks and maintenance ratios.

## Demo

https://lichunbin814.github.io/pages-stockpledge-helper/

## Features

- Simple dialogue-style interface for calculating maintenance ratios
- Basic mode for quick calculations
- Advanced mode for stock price drop and additional investment simulations
- Visual charts showing loan limit usage
- Real-time risk alerts
- Bilingual interface (English/Chinese)
- Mobile and desktop friendly

## Technologies

- React + TypeScript
- Chakra UI Component Library
- i18next for internationalization
- decimal.js-light for financial calculations
