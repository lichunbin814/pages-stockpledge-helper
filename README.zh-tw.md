# 股票質押貸款維持率計算工具

評估股票質押貸款風險，計算維持率的工具。

## Demo

https://lichunbin814.github.io/pages-stockpledge-helper/

## 功能特色

- 簡單對話式介面，輸入持股市值和預計貸款金額即可計算維持率
- 基本模式提供快速試算
- 進階模式可模擬股價下跌及追加投資影響
- 視覺化圖表顯示可貸額度使用狀況
- 即時風險提醒，維持率過低自動警示
- 支援中英文介面
- 電腦手機皆可使用

## 使用技術

- React + TypeScript
- Chakra UI 元件庫
- i18next 多語系
- decimal.js-light 金額計算
